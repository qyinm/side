A FEW THINGS TO KNOW

Small panel.
Clear answers.

What is Side?

Side is a macOS-first desktop app for chatting with models from Pi-supported providers. It lives beside a bottom Dock, with an expandable conversation panel and a global shortcut.

Do I need my own AI account?

Yes. Connect a supported provider using the authentication methods available for it, such as an API key or sign-in. Model access and any usage charges depend on that provider and your account.

Does Side read my screen or run commands?

The current version is a text chat app. It doesn't read your screen or run shell commands. You type the context you want to share. macOS Accessibility permission is used to position the panel beside your Dock.

Where do my conversations go?

Your prompts are sent to your selected AI provider for a response. Provider credentials are stored in Side's local app data. The conversations and model settings are saved locally, so you can resume a chat from history or start a new session.

Which Macs can use it?

The download is for Apple Silicon Macs. Open the DMG and drag Side into Applications. The app and installer are signed and Apple notarized. The minimum supported macOS version is still being verified.
